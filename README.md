# 📱 ZingQuark QR Scan

A fast and smart QR code scanner built with **MIT App Inventor**.

ZingQuark QR Scan doesn't just scan QR codes — it detects what the QR code contains and automatically handles different types of information using your Android device.

## ✨ Features

- ⚡ Fast QR code scanning
- 🔗 Automatically opens website URLs
- 📍 Recognizes map locations
- 📧 Detects email addresses
- 📞 Detects phone numbers
- 💬 Displays regular text
- 🧠 Smart content detection
- 📱 Uses Android intents to open the appropriate app
- 🎨 Clean ZingQuark interface
- 🛠️ Fully editable MIT App Inventor project

## 🧠 Smart QR Detection

ZingQuark QR Scan checks the scanned result and determines what it is.

| QR Content | Action |
|---|---|
| 🌐 Website URL | Opens the website |
| 📍 Location | Opens the location in a maps app |
| 📧 Email | Opens an email application |
| 📞 Phone number | Opens the phone dialer |
| 💬 Text | Displays the scanned text |
